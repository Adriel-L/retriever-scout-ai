# Retriever Scout AI

A RAG (Retrieval-Augmented Generation) assistant that answers questions about UMBC Men's Soccer by combining structured season statistics with semantic search over game recap articles.



## Status

In progress - currently building the data scraping pipeline.

## 

## What it does (planned)

* Scrapes UMBC Men's Soccer schedule, game recaps, and season stats from umbcretrievers.com
* Embeds recap text into a vector database for semantic search
* Routes questions to either structured stat lookups, semantic text retrieval, or both
* Generates grounded answers using an LLM, based only on retrieved UMBC data

## 

## Tech stack

* Python, BeautifulSoup (scraping)
* ChromaDB (vector storage)
* Anthropic Claude API (generation)
* Streamlit (frontend)
